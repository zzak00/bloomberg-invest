Code architecture
backend/src/bloomberg_invest follows Architecture Patterns with Python. Dependencies point inward; every outside system sits behind a port, and bootstrap.py is the one place that picks the implementation.
entrypoints/
translate input, call a service
cli.py · bloombergapi/app.py · FastAPIapi/openapi.py
▼ calls
service_layer/
one module per use case, adapters passed in
ingest.pychunk.pyembed.pyextract.pysearch.pycompany.py
▼ uses
domain/
rules only, imports no other layer
model.pychunking.pyindexing.pyextraction.pyfigures.pydossier.pylabel_map.pytables.py
Pydantic write models, the chunker, the figure check (cell and quote matching, units, periods), agreement and Conflict grouping.
Alongside
views.py: the read models the store returns and the API serves
settings.py: configuration from the environment
config/: line_items/v1.toml (44 line items) and prompts/extract_figures_v1.md; each extract Run records their version and SHA-256
bootstrap.py · composition root
The only file that names concrete adapters. Registries PARSERS, EMBEDDERS and LLMS map a setting to a factory, so switching one is a settings change and adding one is a file plus a line. Heavy libraries load only when used.
