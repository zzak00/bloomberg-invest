Why a figure is rejected
Its source id is not on the page · its value differs from its cell · its value is not in its paragraph · its value is not one number · its unit names no currency, percentage or share count · its line item is not in the label map · its scope is neither consolidated nor company-only.
Attributes by example
Real values from the Maroc Telecom 2025 report. An attribute absent from a node has no value: Neo4j stores no nulls. Every attribute with its meaning: docs/graph-schema.md.
LABEL
Passage: a label, not a node
A node can carry several labels. Every Cell node is :Cell:Passage and every Span node is :Span:Passage.

Passage means what a Fact cites: the table cell or the quoted sentence its value comes from. Reads ask for any Passage without caring which kind:
(:Fact)-[:CITES]->(:Passage)
No node is a Passage alone.
RELATIONSHIPS
No properties on relationships
A relationship is a type and a direction, nothing more. When something was made, and by which tool and settings, is on the Run node that PRODUCED_BY points to.

The local graph holds 54,942 relationships and none has a property.
