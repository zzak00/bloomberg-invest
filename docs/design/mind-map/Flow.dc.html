Data flow
One write path (ingest a filing) and two read paths (search, company figures). Solid arrows are the order of work; dashed arrows show what each step writes to Neo4j.
1 · Ingest a filing bloomberg ingest <pdf> --issuer-isin --issuer-name --doc-type --fiscal-year [--source-url]
Filing PDF
AMMC report, plus ISIN, issuer, doc type, fiscal year, source URL
Store
Copied to data/documents/<sha256>.pdf; the Document is matched on SHA-256
Parse
Docling: pages, sections, tables and cells; its full output saved as JSON
Chunk
Sections up to 2,000 tokens; tables up to 1,500, split between rows
Embed
Qwen3-Embedding-0.6B embeds section path, pages and text
Extract
Azure OpenAI reads each page: HTML tables with cell ids, 4 pages at once
Check in Python
The value must equal its Cell's number or appear in its quote

Every step is a Run
step, tool, tool_version, config, started_at, finished_at, status. A re-run marks old output superseded, linked SUPERSEDED_BY the new Run. A failed Run writes nothing. Redo one step: bloomberg chunk | embed | extract <document id>
