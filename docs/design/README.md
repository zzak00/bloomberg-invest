# Design boards

Snapshots of the Claude Design artifacts, exported on 2026-11-10 when the artifacts were closed. Open the HTML files in a browser; they render without Claude Design. They are not kept in sync with the code: `docs/graph-schema.md`, `AGENTS.md` and the README are the source of truth.

- `mind-map/`: the solution map, as five boards. `Main.dc.html` is the overview; `Flow`, `Schema`, `Interfaces` and `Architecture` detail the data flow, the graph schema, the endpoints and the code layout. `canvas.json` holds the board titles and layout.
- `graph-schema.html`: the graph schema page, every node and relationship with an example.

The analyst prototype stays in Claude Design (https://claude.ai/artifact/AmgEVLBQWWRY2KM4jm1uFP): it runs only there, and it holds report figures that stay out of this public repo.
