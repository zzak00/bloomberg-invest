Graph schema

Every node the pipeline writes for one filing, with each attribute's meaning and a real example from the Maroc Telecom 2025 report. The source of truth is docs/graph-schema.md in the repo.

Passage is a label, not a node

Every Cell is :Cell:Passage and every Span is :Span:Passage. A Passage is what a Fact cites, so reads match (:Fact)-[:CITES]->(:Passage) without asking which kind. No node is a Passage alone.

Relationships have no attributes

Only a type and a direction. When something was made, by which tool and with which settings, lives on the Run that PRODUCED_BY points to. The local graph holds 54,942 relationships, none with a property.

Absent means no value

Neo4j stores no nulls, so an optional attribute (marked ?) is missing from the node rather than empty. superseded appears only once a newer Run replaces the node.

One figure, as stored

(:Organisation {isin: "MA0000011488"})<-[:ABOUT]-(f:Fact {line_item: "revenue", value_as_written: "36 681"})
(f)-[:CITES]->(:Cell:Passage {text: "36 681", row: 1, col: 3})-[:ON_PAGE]->(:Page {number: 4})
(f)-[:FROM_DOCUMENT]->(:Document {doc_type: "annual_report", fiscal_year: 2025})
(f)-[:PRODUCED_BY]->(:Run {step: "extract", tool: "azure-openai"})
(:Table {page: 4})-[:HAS_CELL]->(the Cell)

Consolidated revenue for 2025: 36 681 in MAD millions, read from row 1, column 3 of the first table on page 4.

Unique keys

Neo4j Community enforces uniqueness only (marked UQ); required attributes and types are checked by the Pydantic models every write goes through. Page has no key. The vector index chunk_embedding covers Chunk.embedding, cosine, full precision.

Superseded, never deleted

A re-run marks the earlier Run's nodes superseded = true with SUPERSEDED_BY the new Run, in the same transaction. Reads skip them, except reads by id, so a link to an old Fact or Chunk keeps working.

Why a figure is rejected

Checked in this order; the first that fails is the reason.

  • its source id is not on the page: e.g. the LLM cited t46.0.r8.c2+t46.0.r8.c3, two cells joined. It cites nothing.
  • its value differs from its cell: e.g. 18 002 against a cell reading propres 18 002.
  • its value is not in its paragraph
  • its value is not one number
  • its unit names no currency, percentage or share count
  • its line item is not in the label map
  • its scope is neither consolidated nor company-only

Boxes and pages

Boxes are in PDF points with a top-left origin. The viewer places a highlight as fractions of its Page's width and height, which is why every Page stores its size.
